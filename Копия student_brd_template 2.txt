4. REQUIREMENTS
---------------
    - Requirement 1: Users must be able to create an account using an email address.
    - Requirement 2: The system must send a confirmation email upon successful registration.
    - Requirement 3: Add a reader mode in which you can only read and cannot create blogs, respond to articles, or rate articles.
    - Requirement 4: Registered authors must be able to create, edit, save as draft,
      publish, and delete their own articles.
    - Requirement 5: Every article must contain:
      - Title
      - Author
      - Publication date
      - Category
      - Article content
      - Rating
      - Tags
    - Requirement 6: Authors can pin the photo/video to the post
    - Requirement 7: Adding report to user

    - Performance: 
         - Search must work as fast as it can
         - Add DM
         - Add "block author", so user will never see him in the news recommendation feed or in search and cant get messages in DM if he don't decade to unblock him
         - Users will have avatar and banner with username. User must have username, but if they don't have avatar or banner they will get default avatar and blue banner

    - Security: 
      1. Add Email verification
      2. Add phone verification
      3. Add second password verification(3 is max)
      4. Add reCAPTCHA to registration
      5. Registration must contain:
         - Password
         - Email
         - Name
         - Username
         - Date of Birth
         - Gender
         - reCAPTCHA
         - 5 digital code comes to email
      6. Add account ban
      7. Add account recovery by email/phone
      8. Add account deleting

    - Usability: 
      1. The app must be hybrid and mobile-friendly
      2. The UI must be simple and understandable for newbies
      3. The app must have search and filters
      4. Search results must clearly display the article title, author, publication date, category, 
         and rating.
      5. The website must be accessible using keyboard navigation.
      6. Add settings and private settings
